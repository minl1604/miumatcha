# Miu Matcha

Game quản lý tiệm trà và bánh mèo 2D bằng tiếng Việt.

Xem **[README tiếng Việt](README.vi.md)** để chạy game, chơi, kiểm thử, tái tạo hình ảnh và cấu hình nhận xét AI.

```sh
npm install
npm run dev
```
